# UX house rules

The owner's UX rules, taken from the owner's repos. Each repo with screens follows them.
A builder reads `principles.md` before it writes UI. A reviewer marks `checklist.md` for each changed screen. `a11y.md` holds the accessibility floor and its CI check.
Vercel web-interface-guidelines keeps web mechanics, impeccable keeps critique and polish, and frontend-design keeps visual direction.
Ruling: record ux-house-rules (house UX rules). Skill design-review and the builder and reviewer agents load this folder.
