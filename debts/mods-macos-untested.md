# The four marketplace mods are untested on macOS

- **What.** macOS is untested for all four mods: `token-weather`, `desktop-statusline`, `plain-diff` and `session-board`.
- **Where.** The `claude-settings` marketplace entry in `settings.json`.
- **Decision.** `mods-install-via-marketplace` (mods install from the marketplace, with no installer step).
- **Retire.** Each of the four mods is run on a Mac clone, and the result is recorded in the decision.
