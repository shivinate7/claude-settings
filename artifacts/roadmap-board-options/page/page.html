Best fit

GitHub Projects, as a display only

It sits next to your PRs and shows CI and review state on each card for free. The roadmap JSON stays the one record, and a script copies steps onto the board. It costs nothing and needs no new account.

Works, wrong size

Jira

A fine tool for a team handing work between people. For one person directing Claude sessions, it adds a second record that drifts from the roadmap, and its sprint and points features go unused.

Does not fit

Kong Konnect and KAi

Konnect manages API gateways, and KAi is its assistant for debugging gateway traffic. It has no place to put a roadmap step. It fits only if you one day run your own APIs behind a Kong gateway.

My pick

Keep the roadmap page. Add the GitHub board only if you want to click and drag.

Even then, the board should only show the roadmap, never become a second place where steps get written.

How it would plug in

roadmap/data/steps/*.json (the one record) │ push to roadmap branch ▼ python roadmap/build.py (already runs) │ new: sync step ▼ GitHub Action, project token addProjectV2DraftIssue one card per step updateProjectV2ItemFieldValue status, phase, PR ▼ Project board (read-only by habit)

Drafts and field updates are real GitHub API calls. A board edit would be overwritten at the next sync, which keeps the roadmap the one record.

What you gain

  • Views you can click through: board, table, timeline, and saved filters such as "Waiting on Shiv".
  • PR cards show CI, review and merge state live, with no Claude step writing it.
  • Works in the GitHub phone app. Free on your current plan.

What you lose or pay

  • A new sync script and a token with project access, which is one more thing to keep green.
  • The roadmap page's own extras (cull numbers, briefs in the ask field, gold-standard columns) do not show as nicely in a board. Field limit: 50 per project.
  • Moving a card on the board does nothing unless you also want two-way sync, which brings back the second-record problem.

How it would plug in

Claude session ──(Atlassian connector)──► Jira ticket │ └── also edits roadmap JSON? ← two records or stops editing it? ← build.py, the roadmap page, cull numbers and git history all go

Either path breaks something you rely on. A one-way copy from build.py to Jira is possible, but then it is a worse version of the GitHub board above.

What you gain

  • Strong filters, reports and dashboards.
  • A standard tool if others join you or an employer asks for it.

What you lose or pay

  • A second record, or the end of git history on the plan.
  • Every session write becomes a connector call, slower than a commit and harder to review.
  • Sprints, points and assignees are built for teams. Here they would be empty or made up.
  • Free plan covers up to 10 users. Atlassian's Rovo AI is not on the Free plan. Whether the official Atlassian connector works on Free is unknown; I could not confirm it.
Option 3

Kong Konnect and KAi

Kong Konnect is a hosted platform for running and governing API gateways: routing, security, analytics and developer portals for APIs and AI traffic. KAi is the AI assistant inside the Konnect console, in public beta. Since January 2026 it can open debug sessions on live gateway traffic, answer analytics questions such as "which consumers cause the most 5xx errors", and read gateway settings. Kong also ships a Konnect connector (an MCP server) that works with Claude Code.

None of that is a work tracker. To show you what you would actually see, the mockup below is your account on day one.

Illustrative. KAi's replies are my paraphrase of what Kong says it can see (gateway settings, traffic, analytics and docs, limited by your permissions), not a captured answer.

How it could plug in, if at all

  • As a roadmap or board: it can't. Konnect has no tickets, steps or boards.
  • As a gateway for your own Claude API calls: Kong's AI Gateway can sit between a program and the Claude API to log, limit and price calls. That helps only for code that uses your API key directly. Claude Code sessions on your Max plan don't route through it.
  • As a connector in Claude Code: the Konnect MCP server would let a session ask about gateway traffic. With no gateways, it has nothing to answer.

What you gain

  • Nothing for the roadmap.
  • Later, if you publish an API (for example, a public q_max or Banchi endpoint), real rate limits, keys, analytics and an AI assistant to debug it.

What you lose or pay

  • Paid plans (Plus and Enterprise) after a 30-day trial with free credits. Third-party sites quote very different prices, so I could not confirm a figure.
  • A gateway to run and keep up, on a box that is already fragile (the HA Green holds rule).
