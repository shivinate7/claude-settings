What one yes approves

One yes lets claude-settings sessions open one PR in each repo below, carrying only the change in its row. Five roadmap steps wait on it: c76, c78, c89 part 2, c47 part 2 and c127. Strike any row to keep it out.

  • Each change is a PR in that repo, under that repo's own merge rules and CI. Nothing goes straight to main.

  • One repo at a time. A repo is visited only while no lane of its own is open.

  • Each PR proves its change red then green, and cites the claude-settings step it serves.

  • The project's rule "never push to the other repos" bends only for these rows, only through PRs.
