# Waiting page c190, part 2: a command block on a task

Mockup: `c190-task-command.html`. Screen: `skills/waiting-page/page.html` at 1cc47f01, the task branch of `buildCard`. Its `#pagecss` is that file's CSS, lines 8 to 284. Its `#newcss` holds only this step's changes. Measured with headless Chromium at 390 and 1280, light and dark. Fonts fall back offline, so a height that depends on text is approximate. `layout.py devices` printed "unknown" for this repo, so the mockup draws the brief's sizes.

1. Shown or hidden. A (pick): the block shows the command open. C: the command sits in a closed `<details>` ("Show the command"), and Copy works while it is closed. Gain of A: the owner reads what will run before pasting it, which matters for a delete. Loss of A: it departs from house rule ux-machine-text-hidden, which puts code only in a closed disclosure. Gain of C: it keeps that rule. Loss of C: one more press to read, and an unread delete is easy to paste. Pick: A. Owner grant: yes. Not blocking.
2. Long lines. A (pick): each written line is a block `<span class="ln">`. A long line wraps inside the block, and its wrapped part hangs 2ch in. B: a line keeps its length and scrolls inside the block; the block takes focus so a keyboard can scroll it. Measured: the brief's own command already overflows a 390 card, so B would hide its end on every phone. Gain of A: the whole command shows on a phone. Loss of A: a break can fall after a hyphen ("old-" then "b"); the hanging indent marks it as one line. Pick: A.
3. Copy button. `<button class="btn alt cmd-copy">` with `<span class="go">Copy</span><span class="ok" aria-hidden="true">Copied</span>` in one grid cell. Measured: 89 by 44px in idle, Copied and failed states, at each size and theme. So a press moves nothing (ux-press-moves-nothing). Its name is "Copy the command for No. 39", the act and its target (`a11y.md`).
4. Answer at the press. `.cmd-say` sits beside Copy and is the live region. Idle: "Command". Success: the button says "Copied" for 2 s, and the status adds a hidden " Copied." so the word shows once (ux-label-once). Failure: "Not copied. The text is selected; copy it by hand." in `--due`, and the command text is selected. The head row is 44px in every state; the content below does not move (measured).
5. Copy copies `it.command` as written, never the text on screen. A refusal is likely: in this mockup Chromium refused `navigator.clipboard.writeText` with a permissions-policy error in a `srcdoc` frame, even with permission granted. The page runs in a frame too, so the failed state is needed. Departs from: none. The bar's Copy (`page.html`, the `$("copy")` listener) has the same try-then-select fallback. Give both one copy helper.
6. Place: after `ol.steps` and before `.links`, so the step "Paste the command and run it" sits just above it. A task with no `command` keeps today's card (state `nocmd`).
