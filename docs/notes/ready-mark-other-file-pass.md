- ready-mark-other-file-pass: PR #3765 (the ready-mark guard change), decision ready-mcp-mark-guard (the guard on ready marks made over MCP). A Bash command that names a background run's output path counts its whole result. So `cat <output path> <other file>` counts a pass line in the other file. The decision says a pass in another file counts for nothing. Count a result only when its command names no other file. Seen: 2026-11-21 x1
