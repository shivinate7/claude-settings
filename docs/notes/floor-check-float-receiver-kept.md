- floor-check-float-receiver-kept: A receiver that is only a float, and not a plain name, keeps its 'int.is_integer' member line when another function in lint/check_python_floor.py binds the same name to an int. That is a false alarm. Examples: `float(x).is_integer()`, `math.sqrt(n).is_integer()`, `d["k"].is_integer()`, `o.ratio.is_integer()`, `(-1.5).is_integer()`. The check flags fewer cases than main, but it keeps these. Cause: `IntMembers.has_int_read` keeps any receiver that `is_not_int_expression` does not know, and that function covers no call, subscript, attribute or negated float. Seen: 2026-11-25 x1
