- desktop-delivery-marker: a desktop send counts as delivered only when its result text holds `(delivery: delivered;` (DESKTOP_DELIVERED in `lint/_transcript.py`). Any other delivery state, such as queued or undelivered, reads as undelivered. The form is measured, not documented: no vendor document states it. If the app changes the text, a delivered send stops counting, which fails on the safe side. A failed desktop send whose error text names an act (such as `git push`) counts as a failed try of that act in `failed_tries` (`lint/report_guard.py`), as the older send tool does. Seen: 2026-11-25 x1
