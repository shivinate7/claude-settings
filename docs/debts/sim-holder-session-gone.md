# A lane whose session is gone can hold a phone with no chat path

- **What.** Gap 7 of the sim-lease gaps plan (commit b7bc81daa). At 12:09 CST on 2026-11-07 the Degen lane `ios-ship-account` (sim-test pid 79492) took Duo 1. Its session was off the session list, so no message could reach it. The gap 1 to 3 fixes (the reuse lease, lock safety, the reset of a stopped run) and the builds for gaps 5 and 6 are in PR #2787 (the sim-lease gaps PR). Two things stay open. A live holder whose session is gone keeps the phone until its pid ends or a run limit stops it. For a test run, SIM_TEST_MAX_RUN (1800 s by default, unmeasured) stops the xcodebuild child, and sim-test gives the lease back. It is a run limit, not a lease limit. A direct holder (`sim-lease take --pid`) has no limit (note `sim-silent-holder-limit`; decision sim-lease-tool, ruling 9). A session with no lease can still drive a booted phone (debt `sim-drive-without-lease`).
- **Where.** bin/sim-lease, the take, wait and reap path (recovery by dead pid), and the reuse path in bin/sim-test (`take_lease --reuse`), which takes a reuse lease.
- **Decision.** `sim-lease-tool` (ruling 5: recovery reaps a dead pid, not a live silent holder).
- **Retire.** Blocked on a decision: ruling 9 of sim-lease-tool sets no time limit for a live holder, so no test can show this closed yet. If a limit is set, `lint/test_sim_holder_gone.py` (not yet written) must pass: a live holder past that limit releases the phone, and a second run waiting on the tool gets it with no chat.
