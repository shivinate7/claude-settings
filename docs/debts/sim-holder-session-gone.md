# A lane whose session is gone can hold a phone with no chat path

- **What.** Gap 7 of the sim-lease gaps plan (commit b7bc81daa). At 12:09 CST on 2026-11-07 the Degen lane `ios-ship-account` (sim-test pid 79492) took Duo 1. Its session was off the session list, so no message could reach it. The gap 1 to 3 fixes (the reuse lease, lock safety, the reset of a stopped run) and the builds for gaps 5 and 6 are being made on branch `claude/sim-lease-gaps`, not on main. Once they land, one thing stays open: a live holder whose session is gone keeps the phone until the silent-holder limit of 1800 s, which is unmeasured (note `sim-silent-holder-limit`). A session with no lease no longer drives a booted phone: `simulator-drive-lease` refuses it (decision `sim-test-is-the-one-boot-path`, ruling 12).
- **Where.** bin/sim-lease, the take, wait and reap path (recovery by dead pid), and the reuse path in bin/sim-test, which takes no lease on main.
- **Decision.** `sim-lease-tool` (ruling 5: recovery reaps a dead pid, not a live silent holder).
- **Retire.** `lint/test_sim_holder_gone.py` passes: a live holder past the silent-holder limit releases the phone, and a second run waiting on the tool gets it with no chat.
