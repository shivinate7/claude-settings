# scratchpad-owner misses some run forms

- **What.** The scratchpad-owner check does not read these forms as a run of another agent's script, so an agent can run that script through one and not be asked. F is the scratchpad file: `uv run F`, `npx tsx F`, `bun run F`, `py F`, `pytest F`, `python3 -m pytest F`, `stdbuf -oL python3 F`, `setsid python3 F`, `python3 < F`, `cat F | python3`, `bash -c "python3 F"`, `sh -c "python3 F"`. The check reads only the first command of a segment, so a run in a substitution or subshell is missed too: `out=$(python3 F)`, `echo $(python3 F)`, `(python3 F)`. Fix: loop over `command_indexes`. Also missed on verify: `deno run F`, `make -f F`.
- **Where.** `hooks/guard.py` `scratchpad_owner_hit` reads only `_RUNNER` names, with the file as the first plain argument, or the file as the command word. The runner list is `_RUNNER` in `hooks/guard_core.py`, which `_runs_written_file` there also reads, so a widened list changes that rule too. `nested_script` in `hooks/guard_core.py` gives the text of `sh -c` and `bash -c`, and the check does not use it.
- **Decision.** `scratchpad-owner` (an agent asks before it runs another agent's scratchpad script).
- **Retire.** Fix: judge the text `nested_script` gives as one more command, and widen the runner list for this check only, or test the other rule as well. Check: an ask case for each form above in the scratchpad-owner family of `hooks/test_guard.py`, with an allow case for the agent's own file: `hooks/test_guard.py`.
