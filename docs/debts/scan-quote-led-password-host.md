# The export scan passes a database address whose password starts with a quote and whose host starts with a code character

- **What.** A pasted database address whose password starts with a quote or backtick, then `@` and a host that starts with a quote, brace, bracket, paren or `|`, a dotted template such as `{host}.example.com` included, passes the export scan. The three forms are `postgres://admin:'x1y2@{host}/app`, `postgres://admin:"abc@{db_host}/app` and `postgres://admin:"Sup3rS3cret"@{db_host}/app`. The scan passes them on the head commit of PR 2372 (branch `export-scan-key-false-alarms`), `7f25552edcde580d00bbcf2bc5f721e126022f33`. A literal dotted or IP host refuses. Claude could paste such a line by mistake from a config or a script. The owner accepted this as a known limit to merge PR 2372, which clears about 2,500 false alarms on code text (owner's figure, page item 456 a, 2026-11-09 13:09 CST). The same review also leaves three rarer limits: a user part with `$(cmd)`, `o'brien` or `a|b`, a literal password and a dotless host.
- **Where.** `skills/waiting-page/export_page.py`, the `url-credentials` shape in `SECRET_SHAPES` and its helpers `URL_USER`, `URL_PLAIN_PASSWORD`, `URL_QUOTED_PASSWORD` and `URL_HOST_START`.
- **Decision.** `waiting-data-in-repo` (a copy of the page lives in the repo; the scan runs before any write), and the owner's answer on the waiting page, item 456 a.
- **Retire.** A password that starts with a quote and ends with a non-quote refuses. The fix for that is one line: a password branch placed before the host-checked quoted branch. On a test of that one-line change against the head's pattern, it closes forms 1 and 2 only. Form 3, a password that starts and ends with a quote before a host that starts with a code character, still passes, so it needs a further change. The code forms `"http://h:"+port+"@"` and `"https://a"})];U&&(c=I==null||x:y@b` must stay green. A case for each form in `skills/waiting-page/test_export_page.py` goes red first. A review scratch copy of the one-line change kept all 236 red and 128 green rows.
