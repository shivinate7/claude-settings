# Env-file guard refuses some safe commands

- **What.** The env-file guard (`hooks/guard_env.py`) refuses four safe forms: `ag -f` and `ack -f` (`-f` is a boolean flag), `grep -r --exclude=.env`, and `rg -t py .env`. All four are safe. None reads a file's contents.
  - A folder whose name starts with `.env`, such as `.envs`, is refused for mkdir, git add, cat and cd. The shell guard allows files inside it. The Read and Edit deny list refuses files inside it too.
  - A word that starts with `.env` and names no file is refused, such as `jq .environment f.json`, `jq .envFrom f.json` and `yq .envs f.yaml`. Main allowed these. `jq .env` was already refused.
  - Incident, Nov 1 2026 23:37 CST: the guard refused a coordinator Bash call that only wrote a lane brief through `cat > <file> <<'EOF'`. The quoted body named `bash <<EOF ... cat .env` as prose. Cause: `strip_heredoc_bodies` (the guard code in `hooks/guard_core.py` that strips heredoc bodies) matched a shell heredoc in the body text, so it kept every body in view. `env_refusal` (the shell env-file check) then read the prose as a read. No env file was read or written.
  - Incident, Nov 1 2026 ~23:41 CST: a triage (session 5) Bash call wrote a roadmap JSON note through `python3 - "$W" <<'EOF'`. Python runs that body, so the guard kept the body and read it as shell. The python escape `\'` in a single-quoted python string flipped the shell's quote reading, so later prose naming a `.env` folder read as bare words. No env file was read or written.
- **Where.** `hooks/guard_env.py` (the env-file guard) and `hooks/guard_core.py` (the shared guard code).
- **Decision.** `env-file-stays-unread` (no session reads or writes an env file's contents; a quoted heredoc body is text).
- **Retire.** Status: PR #1082 (the env heredoc fix) fixed incident 2 and incident 1's escaped-quote cause. PR #1186 (interpreter string data read at its shell spots) fixed a backtick or `$( )` inside a quoted python or node string. Each passes as a test. Each other form in What stays open until its own test passes.
