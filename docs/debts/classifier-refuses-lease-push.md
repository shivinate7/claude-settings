# Auto mode refuses a lane's lease push to its own branch

- **What.** The auto-mode classifier refuses `git push --force-with-lease` (bare with `--force-if-includes`, or `=<branch>:<sha>`) to a lane's own branch, though the force-push guard allows it. Nine refusals, 2026-11-02 to 2026-11-08: lanes worktree-base-copies-remove (replacement PR #1064), tci-6 (#1087), page-answered-sink (#1137 for #1129), child-claude-md-dedupe, call-judge-widening, red-main-flag-who-types, mutate-guard-cap (#1211 for #1210), restore-roadmap-fork-test (#1233 replaced) and revive-1042 (#1971 for #1949). Each time the lane rebuilt on a new branch and PR, or left a bad commit subject or an empty trailer commit in place.
- **Where.** The `autoMode.allow` list in `settings.json`, which has no entry for this push. The refusals reach the owner under decision `refusals-reach-the-owner` (a refusal goes to the owner).
- **Decision.** `stale-safe-force-push` (a forced push is safe when it cannot overwrite newer work), which allows this push off the default branch. `auto-mode-owner-acts` (owner acts the classifier allows) names this record as the incident home of its "Own Branch Lease Push" entry.
- **Fix.** Step `lease-push-c-and-d` (a lane can fix its own branch): part d, the red-run check's remedy names no force push, is on main (PR #1255). Part c, the "Own Branch Lease Push" allow entry, is PR #1316. Lane lease-remedy-form's PR #1967 also carries the entry, its test, and a guard remedy that names the sha lease.
- **Gap.** Unmeasured: the granted entry quotes `origin <branch>`, but lanes push `origin <src>:<branch>`, as lane lease-remedy-form did when it was refused. Whether the classifier reads the entry as covering that form is not yet tried.
- **Retire.** PR #1316 lands, and `hooks/test_auto_mode_allow.py` holds the case that pins one "Own Branch Lease Push:" entry in `autoMode.allow`. A lane's lease push in the `origin <src>:<branch>` form then goes through.
