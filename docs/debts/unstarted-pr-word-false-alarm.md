# The Unstarted wait check refuses four right lines that hold a PR word beside a waiting word

- **What.** The Unstarted wait check judges each clause alone. A clause with no waiting word joins the item before it. A clause with a waiting word starts a new item when a short name comes before that word, so a lane name holding "merge", "pr" or "land" beside "when" or "needs" reads as a PR wait. Four lines of this kind are refused on this head: "checkin-cancel-on-merge: measured conflict in hooks/stall_watch.py with the stall-watch branch, starts when that builder pushes; draft-against-draft line, pace reader from PR spans: not briefed yet", "merge-tool-refactor: needs the owner's pick (see bin/merge)", "pr-reader (edits bin/pr.py): starts when the brief is ready", and "none; all lanes started, PR #3916 awaits review". Main passes all four, by code read: each names a file or starts with "none". Way round until fixed: give each item its own bullet, and in an item whose lane name holds merge, pr or land, use no waiting word. Checked on this head: "checkin-cancel: the stall-watch builder pushes first" passes, and "checkin-cancel-on-merge: the stall-watch builder pushes first" is refused.
- **Where.** `lint/report_guard.py`: `_UNSTARTED_LANE_WAIT_RE` matches "pr" in "pr-reader" and "merge" in "checkin-cancel-on-merge", since a hyphen ends a word. `_starts_item` and `_unstarted_units` make the split, and `unstarted_problem` judges each unit.
- **Decision.** `guard-remedy-not-to-owner`, a Stop refusal's steps live in its record, not in chat. Its Unstarted guard section now states the split rule and the two accepted wordings this debt is about.
- **Retire.** Closed when `lint/test_report_guard.py` holds a case for each of the four lines, which is red on this head, and it passes after the split starts an item only at a lane name followed by a colon.
