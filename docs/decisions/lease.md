## Built

- **The tool**, `hooks/lease.py`: take, give back, lift and show. A lease is the ref `refs/heads/lease/NAME` on the remote. A take is one force-with-lease push.
- **The record form.** A commit with an empty tree. Its message lines are `lease NAME`, `holder:`, `repo:`, `taken:` and `roster:`. A give back or a lift pushes a released record with `expires: 0`, and never deletes the ref. A taken record has no `expires` line.
- **The holder id.** `session_X` for a cloud id `cse_X`, else the local session id, else none. With no id, take and give back refuse.
- **The bounded read.** All git calls of one read share 10 seconds, and one push has 30. A read that fails, or runs past its time, is unknown and never free.

**Not built:** every guard that reads a lease; the roster's local ids; roster removal; the page button; the merge lock's move into the family (the merge lock still uses `refs/heads/merge-lock/<base>`); the merge-role lease; and the removal of the role file (`write` in `hooks/session_role.py` still writes it).

Nobody leans on a lease before that lands.

It is unmeasured in a cloud session and on Windows, and an unmeasured platform fails closed.
