# A reply line that compares the work with main cites a read of main

## The ruling

The main-claim check lives in the Stop hook `lint/report_guard.py` (rule `claim-vs-main-needs-read`, function `main_claim_problem`). It refuses a reply when a line of it says how the work compares with main and cites no read of main on that line. It extends the answered-source check (decision `answered-needs-source`) and shares its line reader, code-span strip and hash pattern. It runs on any turn, landed or not. One refusal per turn lists the lines and joins any other reason. A rewrite after a missing-report refusal is checked too, once. A rewrite after a main-claim-only refusal stays quiet, as with the answered and Done-format refusals (`stop_hook_active`). A rewrite with no refusal before it stays quiet too.

**What counts as a claim.** A line of the last reply, in any case, outside fences, that holds one of these phrases as whole words: "not a regression", "no regression(s)", "not worse than main", "worse than main", "same as main", "main's own", "already on main", "pre-existing on main", "matches main", "regression(s) from main". "Not a regression" and "no regression" count with no other word on the line. The check first removes emphasis marks at word edges (`*`, `**`, `_`, `__`; the constant `CANNOT_EMPHASIS_RE`), so "**not worse** than main", "_not a regression_" and "__No regression__" are phrases. A snake_case name keeps its underscores ("no_regression_test" is no phrase). "The" may stand before main and "branch" may follow it ("worse than the main branch"). A hyphen joins words into a name, so "not-worse-than-main" is no phrase. A code span that holds only `main` is read as the word ("not worse than `main`" is a claim). Any other code span is blanked, so a claim that sits only inside one is a mention, not a claim.

**What counts as a cite.** One of these anywhere on the same line, before or after the claim and whatever it names. A source inside an inline code span counts. The list is closed. It holds a path with a line (`file.ext:123`), `origin/main`, `main@<sha>`, and `git show main:` or `git show origin/main:`. It holds a commit hash next to the word main ("main at 36807ad19"; a hash holds a letter a-f, so "20261112" is no hash). It holds "main screenshot" or "main's screenshot" with a path or URL. A bare "main", a path or file name with no line, a time, an item number and a `#<n>` PR ref are no cite. The hash pattern is the constant `DONE_HEX`, the hex part of `DONE_REF_RE`, with a letter required on top.

**What is exempt.** A hedge word on the line, as a whole word: "unmeasured", "unknown" or "not read" ("not ready" is no hedge). A line that ends in `?` asks and claims nothing. Fences opened by ``` or by ~~~ are skipped. The nouns "regression test(s)", "regression suite(s)" and "regression testing" are a test count, not a claim ("No regression tests were added."); "No regression in the layout." stays refused. `main` before `.` and a letter, or before `(`, is a file or call name: "matches main.py" and "same as main()" are no claim. "main's own" is a claim only after is, are, was, were or be. It is also a claim before `.`, `,`, `;`, `:`, `)`, `]`, a closing quote, an em dash or en dash, a spaced hyphen (" - " or " -- ") or the line end. So "main's own CI is green." is no claim. "The glitch (main's own) predates this lane." and "The glitch — main's own — predates this lane." are claims.

**Named incident.** The Downloads filter open-Duo layout was called "main's own, not a regression" with no read of main behind it (degen report row D5). The tests hold that line as a replay, with a cited twin that passes.

Risk kind: likely risk. Cost: a regex over the reply. No process, no file beyond the one bounded read of `hooks/guard.py` the Stop hook already makes at load (unmeasured). `MainClaimTests` in `lint/test_report_guard.py` proves it by watching every file the check opens: exactly the transcript and `hooks/guard.py`.

Known limit: code reads phrases and tokens, not what they cite. A line that cites a path with a line for another reason passes. `origin/main` named on the line counts as a cite although the line may not have read it. The cite list is closed: a read of main in other words ("checked main", "diffed against the base") is no cite. A claim worded another way ("unchanged from main") is not read. A line that ends in `?` is skipped, even when it asserts. A hedge word anywhere on the line exempts it, even a hedge about another thing. A line about what a rule matches, such as "the guard matches main and master", is refused. The escape is a code span round the whole phrase (`` `matches main` ``). A span that holds only `main` is read as the word.
