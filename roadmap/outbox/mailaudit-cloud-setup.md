- Fact for a reference topic (cloud environments): the cloud image ships Playwright's Chromium in /opt/pw-browsers (revision 1243, the build Playwright 1.63.0 needs, with its system libraries validated) and sessions set `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers` and `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`. A setup-script `playwright install` without that path downloads a second copy into /root/.cache/ms-playwright, which sessions never read.
