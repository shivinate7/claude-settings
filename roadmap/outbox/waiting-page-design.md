Review-page standard, taken from an outside interview page shiv shared Oct 27 02:23 CDT (cmsg_01DoF7thf3iq2Srr1UsfXgh2DrFwwCVeSEX2GFLj7CxtiZ): (1) each design question draws only the part of the screen it asks about, one small drawing per option, with the full mockup optional; (2) a coloured edge marks what differs between options; (3) "open this state in the full mockup" deep-links to the exact state, so a design carries named states; (4) each question names the spec rule or plan item it would change; (5) combined answers such as "A+B" are allowed when options can coexist; (6) drawings are real HTML text, not images.
